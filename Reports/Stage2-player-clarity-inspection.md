# Stage2 플레이어 선명도 확인

2026-10-27. 실제 Stage2 재생 중 약 16.689초의 달리기 자세를 동일 시점·카메라·해상도로 비교했다.

- 카메라: Built-in, orthographicSize 5.9268, 1920×1080. 카메라에 블러 후처리 컴포넌트가 없고 플레이어는 Sprites/Default 머티리얼을 사용한다.
- 캐릭터 PSB의 생성 아틀라스: 2048×2048, Bilinear, DXT5, 밉맵 12단계, mipMapBias 0.
- 실제 캐릭터의 화면상 높이: 약 217px. Game 뷰 확대 배율은 확인 시점 약 0.3574여서 표시 크기는 약 78px에 해당한다. 편집기 창 배율은 빌드 출력 해상도와 구분해야 한다.
- mipMapBias만 일시적으로 0 / -0.75 / -1.5로 바꿔 같은 달리기 자세를 렌더링했다. -0.75에서 원본보다 얼굴과 머리카락·옷 가장자리가 선명해졌고, 더 강한 음수 값에서는 계단 모양 가장자리도 증가했다. 밉맵 선택이 부드러움에 기여한다는 직접 비교이며, 움직임 중 깜빡임의 정량 검사는 아니다.
- DXT5 압축 사용은 확인했으나 압축을 해제한 원본과 비교한 검사는 하지 않았으므로 압축의 기여량은 확정하지 않는다.

비교 파일:

- `Captures/PlayerClarity/Gameplay-bias-075.png`: 같은 자세, 임시 mipMapBias -0.75.

검사 후 텍스처 bias는 0으로 복원하고 Play 모드를 종료했다. 플레이어 원본 PSB·임포트 설정·씬·게임 코드는 이번 검사에서 변경하지 않았다. 콘솔 오류 0건.

수정 방향: 먼저 Game 뷰 1:1 또는 충분한 표시 크기에서 확인하고, 실제 출력에서도 더 선명한 표현이 필요하면 캐릭터에만 약한 음수 밉맵 bias를 적용해 이동 중 깜빡임을 비교한다. 밉맵을 전부 끄거나 Point 필터로 강제하는 것은 선의 계단 현상과 깜빡임도 늘릴 수 있으므로 이번 확인만으로 기본값으로 선택하지 않는다.
