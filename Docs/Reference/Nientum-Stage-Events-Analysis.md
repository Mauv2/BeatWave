## 맵과 연출을 구분해서 파악할 것

- **맵 구조:** 길게 이어지는 바닥, 짧은 부유 발판, 위아래 층, 깊은 빈 공간이 번갈아 나온다. 작은 단차만 반복하기보다 공간의 구조를 바꾼다.
- **고정 무대:** 진행을 잠시 멈춘 화면에서 등장 대상·조명·입자로 사건을 전달한다. 이야기 연출과 정지 판정 구간을 혼동하지 않는다.
- **점프:** 이륙할 자리, 공중 표식·노트, 도착할 발판이 함께 읽혀야 한다. 캐릭터의 공중 동작에 색 발광·원형 판정·금색 잔광을 겹친다. 직접 관찰만으로 자동 점프 조건과 입력 규칙은 확정하지 않는다.
- **갈라짐/붕괴:** 정적인 틈, 파편, 바닥의 실제 분리/낙하를 별개의 증거로 다룬다. 이번 재검토에서 특정 바닥이 붙어 있다가 갈라지는 정확한 연속 장면은 확정하지 못했다.

## Stage2 적용 제안 — 원작 관찰과 구분

현재 Stage2의 경사와 21개 틈 도약은 공간 변화의 일부다. 니엔텀에서 보이는 사건의 대비를 강화하려면, 기존 음악의 특정 구절에 사건을 소수 배치하는 편이 어울린다.

1. 연타 구간: 기존 성문 앞에 카메라를 고정하고, 봉인 문양과 석상의 반응을 보여준 뒤 문이 열린다.
2. 강한 구절 전환: 석교 균열을 예고하고, 발판 조각의 이동·낙하와 먼지를 보여준 뒤 아래 회랑이나 건너편으로 이동한다. 이는 BeatWave용 설계 제안이며 원작의 확정된 동작 순서가 아니다.
3. 후반 성당: 큰 도약 전 착지면을 먼저 보여주고, 공중 노트·잔광과 착지 파동을 연결한다.

구현할 때에는 기존 채보/판정과 음악 시간을 기준으로 지형·캐릭터·노트·카메라를 함께 설계해야 한다. 장식만 갈라지고 실제 바닥이나 이동 경로가 그대로인 상태를 완성된 붕괴 사건으로 취급하지 않는다.
