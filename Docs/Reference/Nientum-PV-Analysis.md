## BeatWave Stage1에서 구현할 연출 기준 — 제안

1. **노트 접근**
   - 시소 앞에 첫 노트를 놓고, 이어서 도약 준비 위치의 두 번째 노트를 배치한다.
   - 위쪽 목표 발판과 공중 경로를 미리 화면에 보여준다.

2. **타격과 발판 반응**
   - 타격 프레임에 노트 위치에서 짧은 빛·파편 효과와 판정 문자를 보여준다.
   - 두 번째 판정 시점에 시소의 기울기와 캐릭터의 도약이 이어지도록 만든다.
   - 판정 실패 시에도 진행이 막히지 않는 연출로 할지, 실패에 따른 발판 반응을 다르게 할지는 구현 전에 정한다.

3. **도약과 카메라**
   - 현재 Stage1 경로는 기본적으로 오른쪽으로 이동한다. PV와 같은 왼쪽 위 도약을 구현하려면 해당 구간에 별도 이동 경로가 필요하다.
   - 캐릭터 이동 경로와 노트 위치가 같은 음악 시간 기준 경로를 사용하도록 유지한다.
   - 카메라는 목표 발판 쪽 공간을 확보하고 상승을 따라간다. 콤보 등 UI는 화면에 고정한다.
   - 홀드가 점프 중에 이어진다면 연결 선도 실제 도약 곡선을 따라 배치한다.

4. **착지와 일반 진행 복귀**
   - 착지 후 정상 이동과 노트 판정이 이어지도록 연결한다.
   - 이벤트 경로의 끝 위치·시각을 다음 일반 이동 경로의 시작 위치·시각과 맞춘다.
   - 일시정지 시 캐릭터, 발판, 노트 효과와 카메라도 같은 진행 시점에서 멈춘다.

원작과 구별할 것:
- PV의 장면 편집 컷을 게임 속 이동이나 전환이라고 단정하지 않는다.
- 실제 음악 박자에 맞춘 연출 수치는 BeatWave에서 사용할 곡과 차트를 기준으로 결정한다.
- 현재 문서는 참고 분석이며, 시소 연출 구현은 아직 하지 않았다.
