# Stage1 방향 전환 시소 구간

사용자 요청에 따라 점프 지점마다 배치했던 발판을 제거하고, 초반 맵을 위로 확장했다. PV 00:28~00:30의 시소 반응과 방향 전환을 참고한 전용 구간이다.

## 플레이 흐름

- 음악 4.38초: 기존 길의 시소에서 왼쪽 위 섬으로 도약.
- 5.70초: 왼쪽 섬에 착지하고 시소까지 이동.
- 6.05초: 방향을 바꿔 오른쪽 위 섬으로 도약.
- 7.75초: 오른쪽 위 섬에 착지.
- 8.15~11.00초: 오른쪽으로 내려가며 기존 길에 합류.
- 이후 기존 이벤트·동굴·후반 구간으로 이어진다.

시소는 이 구간의 두 곳에만 배치했다. 새 지형은 출발 발판 확장, 왼쪽 위 섬, 오른쪽 위 섬으로 구성한다. 기존 풀·흙 타일을 사용하고, 다음 발판을 안내하는 별 경로와 상단 시계 아치를 추가했다.

## 판정과 종료 규칙

- 미스는 체력과 콤보에 반영된다.
- 체력이 남아 있으면 노트 성공 여부와 무관하게 시소 회전과 도약이 음악 시간에 맞춰 진행된다.
- 체력이 0이면 이동·음악이 즉시 멈추고 결과 화면으로 전환된다.
- 좌우 이동에 맞춰 캐릭터와 위·아래 판정점이 돌아간다.
- 노트 위치와 Hold의 시작·끝 위치는 음악 시간 기반 이동 경로에서 계산한다. Hold 몸통은 두 끝점을 잇는 하나의 직선이며, 도약 곡선을 따라 휘지 않는다.
- 일시정지 중 캐릭터·시소·카메라·음악의 시간이 멈춘다.
- 반복 경계가 보이던 Stage1 배경 UV 스크롤을 꺼 전체 배경이 이어져 보이게 했다.

## 검증

- 새 구간의 모든 노트를 놓쳐도 체력이 남아 있는 동안 왼쪽/오른쪽 시소 도약과 기존 길 합류가 완료됨.
- HP를 1로 놓고 미스 처리: HP 0, 이동과 음악 정지, 결과 화면 전환 확인.
- 실제 전체 실행: 도약 14회, 시소 2곳, 탭 판정 71회, 의도된 미스 15회, 결과 화면 도달. 검증 실패 0건.
- 좌우 도약 중 노트와 현재 방향의 판정점이 일치하고 판정되는 것을 확인.
- 기존 판정·음악·동굴 전환 회귀 검증 26개 통과.
- 임시 자동 검증 컴포넌트는 제거했다.

## 고정 연출 이후 음악 전환

- 고정 연출 종료 후 낙하와 화면 암전이 진행되는 동안 음악이 서서히 작아진다.
- 동굴 노트가 전환 중 소모되지 않도록 본 음악과 판정 시간은 멈춘다. 같은 음원의 현재 재생 위치에서 이어지는 임시 AudioSource가 전환 구간의 페이드 아웃을 담당한다.
- 동굴 맵과 노트 준비가 끝나면 보존한 음악 시간에서 재개하고, `CaveEventManager.crossFadeTime`(현재 1초)에 걸쳐 전환 전 볼륨으로 돌아온다. 사용자의 볼륨을 1로 덮어쓰지 않는다.
- 페이드 아웃 길이는 정지 대기 + 도약 + 낙하 + 암전 시간에 맞춘다. 페이드와 임시 음악도 일시정지에 따라 멈춘다.
- 체력 0 종료 규칙은 유지한다.

검증: 별도 Unity 실행에서 기존 판정·동굴 전환 검증을 포함한 38개 항목 통과. 직선 Hold, 좌향 Hold, 조기 해제 Miss, 페이드 아웃/인, 각 페이드 중 메뉴 일시정지, 기존 볼륨(0.63) 정확한 복귀, 재개 후 음악·판정 시간 오차 80ms 미만을 확인했다. 열린 Stage1 편집기는 플레이 진입 후 연결 응답이 지연되어 실제 화면 자동 검증을 완료하지 못했다.
