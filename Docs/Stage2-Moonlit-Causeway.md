- 모든 수평 위치·속도·음악 시간과 234개 기존 채보는 유지한다. 높이 경로만 샘플로 작성한다.
- 홀드 앞뒤 0.35초 안의 경사 전환점을 옮겨 기존 직선 홀드가 경로와 일치하도록 한다.
- 기존 21개 두 박 도약은 유지하고 높이를 1.75–2.1m로 보강한다.
- 기존 바닥 PNG와 실제 경사 콜라이더를 같은 윤곽에 맞춘다.
- 상승 회랑·낮은 폐허·후반 성당에 18m 석조 아치, 달빛 원형 문양과 수호 석상을 배치한다. 교량 아래에는 기둥을 넣어 높이를 느끼게 한다.
- 배경 교차 전환, 전경 난간, 음악 박자 등불, 도약 안내광과 착지 효과를 유지한다. 공유 노트 프리팹은 수정하지 않는다.
- 작업 직전 씬 사본: `Reports/Backups/Stage2-before-elevation-20261027.unity`.

## 구성 원칙

한 성채의 외곽에서 성당으로 이어지는 가로 이동을 유지한다. 긴 석교, 짧게 끊어진 교량, 버팀기둥, 깃발과 촛불을 반복되는 건축 언어로 사용한다. Stage3의 시계 극장, 대규모 낙하, 역주행, 수직 리프트, 종이 하늘 무대는 사용하지 않는다.

기존 170.064초 음원, 234개 채보(홀드 15개와 연타 1개 포함), 모든 수평 위치·속도·BPM·에너지 샘플을 유지한다. 원래 복사 확장된 배치에서 발생한 39개 도약 대신, 노트와 홀드에 맞춰 박자에 정렬된 21개 석교 도약과 지형 높이를 새로 작성한다. 도약은 두 박 길이이며 홀드 앞뒤에 여유를 둔다.

## 2026-10-27 사건 연출 추가

니엔텀의 고정 무대와 이동 전환 분석을 바탕으로 Stage2의 기존 지형에 사건을 추가했다. 원작의 정확한 붕괴 동작을 복제한 것은 아니며 달빛 성채용 구성이다.

- 기존 Mash 시점 약 27.36초: 성문 쪽으로 카메라 구도를 모으고, 청록 봉인 원과 빛이 드러난다. 기존 Mash의 음악 정지 중에는 무대도 멈춘다. 음악 시간이 재개되면 봉인이 확산·소멸하고 기존 성문이 열린다. 별도의 성공 판정이나 입력은 추가하지 않았다.
- 43.958초, 81.809초, 140.893초: 기존 도약 틈을 네 조각의 석교로 채웠다. 1.2초 전 균열빛과 작은 진동으로 예고하고, 도약 시작에 조각 콜라이더를 해제하며 회전·낙하와 먼지빛을 표시한다. 출발·착지 지형과 기존 노트 경로는 그대로 사용한다.
- 해당 구간 카메라는 도약 전부터 조금 넓어져 도착면을 보여주고, 착지에 0.75초의 타원 파동을 더했다.
- 모든 동작은 음악 시각에서 계산한다. 독립 물리 시간이나 새 입력 규칙을 사용하지 않으며 되감기·재시작 시 원상태로 복원된다.

추가 파일: `Assets/Stage2/Scripts/Stage2StageEvents.cs`(시간 기반 연출), `Assets/Stage2/Editor/Stage2EventsBuilder.cs`(기존 씬에 연출 설치). `Build Stage Events` 메뉴로 연출만 다시 만들 수 있다. 전체 Moonlit 빌더도 마지막에 이 설치를 호출한다.

검증: 170.064초 전체 자동 재생에서 234개 판정/Miss 0, 홀드 15개·도약 21개, 메뉴 정지/재개 통과. 노트 머리 오차 0, 홀드 편차 0.0180m, 관측 접근 노트 228/228개가 화면 안에 표시되었다. 합성 입력 검사이며 지연된 편집기 콜백 12회에 검사 입력 시각만 보정했다. 실제 키보드 조작감 검사는 아니다. 컴파일·실행 콘솔 오류 0건.

`Reports/Stage2-stage-events-validation.txt`에는 각 붕괴의 정상 바닥→콜라이더 해제→낙하→정지 재평가→착지 파동→원상 복원 검사 결과를 기록했다. 전체 재생 결과는 `Reports/Stage2-causeway-validation.txt`.

실제 재생 캡처: `Docs/Preview/Stage2-Events/04.png`(약 82.15초 붕괴), `05.png`(약 141.2초 도약), `06.png`(약 142초 착지). 같은 폴더의 01–03은 캡처 예약보다 늦게 도착한 요청으로 찍힌 일반 진행 화면이며, 성문이나 첫 붕괴 시각의 증거로 사용하지 않는다. `Gate-editor-preview.png`는 노트가 없는 편집기 연출 미리보기다.


## 2026-10-27 연결된 사건 구성 (위의 반복 붕괴 구성을 대체)

- 약 27.36초 성문: 기존 기사상 이미지를 7m 크기 환영으로 사용한다. 달 봉인, 성문 조명, 고정 구도가 기존 Mash와 함께 멈추고 음악 재개 후 사라진다.

- 약 140.893초 성당 앞: 붕괴 반복 대신 석재 네 조각이 아래에서 올라와 다리를 복원한다. 출발 약 2.4초 전부터 순차적으로 정렬되어 출발 전 완성되며, 이후 사라지지 않는다. 성문의 달 문양이 금색으로 돌아오고 배경 밝기가 회복된다.
- 43.958초의 추가 붕괴는 제거하고 일반 발판 사이 도약으로 유지했다.
- 원본 노트 234개, 수평 위치/속도, 곡 시간과 도약 시각을 보존했다. 새 노트 종류나 판정 규칙을 추가하지 않았다.
