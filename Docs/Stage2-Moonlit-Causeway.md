# Stage2 — 달빛 성채의 석교 질주

2026-10-26. Stage2에 이미 있는 배경 네 장, 석조 플랫폼·부서진 석교·촛불 플랫폼과 고딕 소품을 사용한 독립 구성.

## 구성 원칙

한 성채의 외곽에서 성당으로 이어지는 가로 이동을 유지한다. 긴 석교, 짧게 끊어진 교량, 버팀기둥, 깃발과 촛불을 반복되는 건축 언어로 사용한다. Stage3의 시계 극장, 대규모 낙하, 역주행, 수직 리프트, 종이 하늘 무대는 사용하지 않는다.

기존 170.064초 음원, 234개 채보(홀드 15개와 연타 1개 포함), 모든 수평 위치·속도·BPM·에너지 샘플을 유지한다. 원래 복사 확장된 배치에서 발생한 39개 도약 대신, 노트와 홀드에 맞춰 박자에 정렬된 21개 석교 도약과 지형 높이를 새로 작성한다. 도약은 두 박 길이이며 홀드 앞뒤에 여유를 둔다.

## 구간별 공간

| 시간 | Stage2 공간과 연출 |
| --- | --- |
| 0–15.80초 | 달빛 성채 외곽. 기존 긴 석조 다리, 원경의 탑, 기사 석상과 깃발. 안정적인 수평 질주로 시작. |
| 15.80–31.03초 | 촛불이 있는 성당 전실. 평평한 길과 반복되는 석조 아치. 27.36초 연타 뒤 음악 시간이 재개되면 성문이 위로 열린다. |
| 31.03–47.19초 | 부서진 버팀기둥 회랑. 약 0.6m씩 높아지는 교량을 두 박 도약으로 연결. |
| 47.19–78.12초 | 지붕 높이의 교량 추격. 빠른 기존 속도에 맞춰 긴 석교와 다섯 차례 안팎의 빈틈을 번갈아 배치. 넓어진 카메라로 착지면을 보여준다. |
| 78.12–108.12초 | 낮은 폐허 회랑. 어두운 성당 배경과 단계적으로 낮아지는 석교, 매달린 깃발. |
| 108.12–123.81초 | 등불이 이어지는 진입로. 진행 방향의 등불이 가까워질수록 밝아지며 다시 성당 쪽으로 올라간다. |
| 123.81–159.82초 | 불빛이 켜진 성당 교량. 촛불 발판, 큰 석조 아치, 짧은 상승과 평탄한 질주를 연결. |
| 159.82–170.064초 | 조용한 성소. 마지막 착지 이후 긴 안전한 바닥 위로 기존 감속과 곡의 잔향을 유지. |

배경은 1.8초 동안 교차 전환한다. 큰 배경, 어두운 중경 건축물, 아래쪽 전경 난간에 서로 다른 이동량을 적용한다. 먼지, 빛기둥, 등불과 착지 잔광은 음악 시간으로 계산하므로 메뉴와 연타 정지 때 함께 멈춘다. 연타 성공 여부에 따른 추가 지형 분기는 없으며, 공통 판정이 음악 흐름을 재개하면 성문 통과 연출이 이어진다.

## 파일과 재생성

- 씬: `Assets/Scenes/Stage2.unity`
- 새 지형 경로: `Assets/Stage2/Data/Stage2MoonlitRoute.json`
- 보존한 채보: `Assets/Stage2/Data/Stage2OriginalNotes.json`
- 제작 도구: `Assets/Stage2/Editor/Stage2MoonlitBuilder.cs`
- 배경·빛·성문 연출: `Assets/Stage2/Scripts/Stage2StageDirector.cs`
- 분위기용 셰이더·메시·머티리얼: `Stage2Atmosphere.shader`, `Assets/Stage2/Presentation/`

`BeatWave/Stage2/Build Moonlit Causeway`로 재생성한다. 기존 레이아웃은 비활성 `Stage2 Original Layout (archived)`에 보존한다. 작업 전 씬 사본은 `Reports/Backups/Stage2-before-moonlit.unity`에 있다. 새 지형·장식·노트 루트는 `Stage2 Moonlit Causeway`에 묶는다.

검사 메뉴는 `BeatWave/Stage2/Validate Music Layout` 및 `Validate Full Music Playback`. 결과는 `Reports/Stage2-causeway-validation.txt`, 실제 재생 화면은 `Docs/Preview/Stage2-Causeway/`에 기록한다. 전체 재생 검사는 판정 API에 합성 입력을 넣고 홀드 끝을 API로 완료하며, 물리 키보드 조작감 검사는 아니다.

## 최종 검증

- 최종 미술 수정 후 170.064초 전체 재생 완료, 234개 판정과 Miss 0 확인.
- 홀드 15개 종료, 석교 도약 21개, 메뉴 시간 정지/재개, 곡이 끝난 뒤 결과 화면 전환 통과.
- 샘플링된 228개 접근 노트가 판정 0.7초 전에 화면 안에 보임. 편집기 검사 콜백으로 관측한 구간에 한하며 전체 프레임의 가독성을 보증하는 수치는 아니다.
- 모든 노트 머리와 이동 경로의 위치 오차 0, 직선 홀드와 이동 마커의 최대 편차 0.0179m.
- 지상 샘플의 콜라이더 높이 오차 0.00000m. 모든 도약이 측정 박자에 정렬되고 두 박 길이를 가짐.
- 최종 전체 검사 중 지연된 편집기 콜백 9회는 검사 입력의 타임스탬프만 보정했다. 실제 음악 시계와 플레이 입력 설정은 바꾸지 않았다.
- 새 분위기·소품 셰이더 오류 0건. 확대된 소품의 반투명 사각 잔상은 전용 머티리얼과 소품 선정으로 정리하고, 원본 PNG는 유지했다.
