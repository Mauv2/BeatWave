# Stage1 음악 구간별 연출

기존 Stage1 음원과 채보, 타일맵을 유지하면서 이동과 화면 구도를 다듬었다. 고정 이벤트의 탭 전용 설정도 유지한다.

- 점프의 출발/착지는 분석된 음악 어택 중 0.3초 이내의 시점으로 조정한다. 짧은 구간을 무리하게 늘리거나 줄이지 않도록 시간 비율을 제한하며, 적합한 어택이 없으면 원래 시점을 유지한다.
- 지형상의 경로는 유지하고 경로를 통과하는 시간만 바꾼다. 플레이어, 노트, 기존 시소가 모두 조정된 경로를 참조한다. 동굴 전환과 음악 종료 경계는 고정한다.
- 카메라는 기본 이동, 시소 방향 전환, 점프 구간, 고정 이벤트, 동굴 낙하, 마무리의 6가지 상태를 사용한다. 기본 이동에서는 캐릭터를 화면 왼쪽 1/3 부근에 두고 다음 노트를 볼 공간을 확보한다.
- 점프는 실제 경로를 읽어 준비한다. 1.5초 이내에 이어지는 점프는 하나의 구간으로 묶고 확대율을 유지한다. 시소에서 캐릭터 방향이 바뀌어도 카메라의 전방 여백을 즉시 뒤집지 않는다.
- 고정 이벤트는 모든 노트 출발점과 판정점을 담는 구도를 한 번 계산하여 유지한다. 동굴 낙하를 따라가다가 암전 중 동굴로 이동할 때 카메라도 바로 정렬하여 화면 복귀 후 뒤늦게 쫓아오지 않게 한다.
- 착지 시 숲에는 낮은 금빛 파문, 동굴에는 푸른 결정 빛줄기, 마지막 점프에는 연녹색 타원 파문을 표시한다. 효과는 기존 Lines 재질을 사용하고 노트보다 아래에 그린다.
- 착지 때 카메라가 내려앉는 움직임은 제거했다. 다음 발판 높이를 미리 반영하고, 마지막 착지가 끝난 뒤 화면을 천천히 넓힌다.
- 효과와 카메라는 음악 시계에 연동되어 메뉴 일시정지 중 함께 멈춘다.
- 동굴 전경 타일에 가리던 캐릭터와 판정점/노트의 표시 우선순위를 높였다. 캐릭터의 SortingGroup 내부 신체·의상 순서는 유지한다.

씬의 Player에 `Stage1MusicDirection`, Main Camera에 `Stage1CameraDirector`가 연결되어 있다. 카메라의 `presentationStrength`로 구간별 구도 변화 강도를 조절할 수 있다.

2026-10-16: Player의 `Stage1TempoMotion`으로 박자·강약 기반 지상 가감속과 달리기 주기 조정을 추가했다. 기존 점프·홀드·구간 경계는 유지한다. 설정과 재생성 방법은 [Stage1-Tempo.md](Stage1-Tempo.md) 참고.

편집기 재적용: `BeatWave > Stage1 > Apply Musical Direction`.
전체 자동 재생 검증: `BeatWave > Stage1 > Validate Full Music Playback`.
검증 기록: `Reports/Stage1-rhythm-validation.txt`.
카메라 조정 후 실행 화면: `Docs/Preview/Stage1-Camera/`. 이전 화면은 `Docs/Preview/Stage1-Direction/`에 남아 있다.

자동 검증은 기존 판정 API로 입력하며 롱노트 종료는 내부 완료 API를 사용한다. 실제 키보드 조작감에 대한 사용자 플레이테스트를 대체하지 않는다.
검증용 PNG 저장 중에는 음악 시계를 잠깐 보존하여 에디터 이미지 인코딩 지연이 자동 입력이나 관찰 시점을 건너뛰지 않게 한다. 실제 게임 실행에는 이 캡처 코드가 포함되지 않는다.

카메라 검증은 일반 입력 0.6초 전 노트 노출, 점프 전 착지점 노출, 기본 이동의 캐릭터 좌우 배치, 고정 이벤트의 구도 유지, 후반 연속 점프의 확대율 유지, 동굴 도착 시 구도 정렬을 검사한다. 최종 실행 결과는 `Reports/Stage1-rhythm-validation.txt`를 참조한다.

카메라 조정 후 전체 재생: 44개 항목 통과, 실패 0개. 점프 14곳 모두 출발 전에 착지 지점이 보였고, 일반 노트 105개 모두 입력 0.6초 전에 보였다. 고정 이벤트 구도 변화는 0.0001, 후반 연속 점프의 확대율 변화는 0.0062였다. 일반 노트와 이벤트 합계 113개 판정, Miss 0, 101.616초에 결과 화면 진입을 확인했다. 음악 페이드와 일시정지 검증도 통과했다.
