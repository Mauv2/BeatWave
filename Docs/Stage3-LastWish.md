# Stage3 — Last Wish / 전체 곡과 지형 개정

## 실행 및 조작

`Assets/Scenes/Stage3.unity`를 열고 Play. 곡 선택 화면의 세 번째 곡에서도 진입 가능하다.

- W: 위쪽 노트. S: 아래쪽 노트. 홀드는 같은 키를 유지한다.
- Mash: 표시된 구간 동안 W 또는 S를 반복 입력한다. 매 타격에 원본 Stage1 타격 이펙트가 발생한다.
- ESC: Stage1의 이어하기·다시하기·곡 선택·타이틀 메뉴.

Stage1의 점수·체력·콤보 UI, 메뉴 기능과 이미지, 일반·홀드·Mash 노트 이미지는 유지했다.

## 이번 편집 내용

- 경로 종료 시각을 고정 숫자 대신 실제 `AudioClip.length`에 연결했다. 곡 끝의 잔향까지 경로가 있으며 결과 화면은 음악 종료 후 열린다.
- 마지막 Mash 대기를 기존 약 3.95초에서 1.8초로 줄였다. 앞쪽 주행에 일반 노트 6개를 추가하고 최종 이동 위치를 x=224에서 x=248로 확장했다.
- Mash 횟수, READY/클리어 문구와 원형 진행률 표시를 제거했다. 입력 안내 `MASH W / S`만 표시한다. 내부 성공 판정은 유지하며 정해진 전환 시각에 한 번만 점수를 반영한다.
- 내부 목표를 넘긴 뒤에도 Mash 입력을 계속 받는다. 각 입력마다 노트와 원이 짧게 반응하고, Stage1의 타격 파티클이 발생한다. 파티클은 0.6초 뒤 정리된다.
- 직선 6구간, 오르막 4구간, 내리막 3구간, 시소 점프 1개로 재배치했다. 지하의 긴 직선과 상층의 마지막 직선이 짧은 경사 사이에 쉼을 만든다.

## 코드 외에 변경한 씬·데이터

- `Stage3.unity` / `New floating walkways`: 경사 발판, 평지 발판과 충돌체 재배치. 지상은 넓은 아치 교량, 지하는 낮은 청색 석판, 상층은 얇은 밝은 석판으로 구성했다.
- `Section landmarks - colonnade archive and dawn`: 지상 부서진 아치 3곳, 지하 지지대·기록실 프레임·청색 조명 3곳과 긴 처마, 상층 금색 장식 3곳 추가. 간격도 구간마다 다르다.
- `Mash input hint`: 세 Mash의 횟수 표시 오브젝트를 입력 안내로 교체하고 진행 원을 제거했다.
- `Last Wish finale`, `Final wish shockwave`: 피날레 위치와 타이밍을 마지막 주행 뒤로 이동했다.
- `LastWishChart.json`: 일반 노트 105개(홀드 5개 포함)와 Mash 3개, 총 108개 판정.
- 기존 Stage3용 새 배경과 발판 텍스처를 활용했다. 이번 개정에서 비트맵 이미지는 추가하지 않았으며, Stage1의 배경·땅 이미지는 사용하지 않는다.
- 재생성 전 씬은 `Reports/Stage3-before-rebuild-날짜-시간.unity.bak`으로 별도 보관한다.

Mash 구간에도 음악은 계속 재생된다. 실패하면 한 번의 Miss를 적용하고 지형 전환은 진행한다. ESC는 음악·이동·연타·붕괴 연출을 정지시키며 재시작은 모두 초기화한다.

## 관련 구현과 검증

- `Assets/Stage3/Scripts/Stage3Session.cs`의 `Stage3Route`: 전체 곡 길이와 경로.
- `Assets/Stage3/Scripts/Stage3Gameplay.cs`: 이동·카메라·배경 색과 원본 판정 연결.
- `Assets/Stage3/Scripts/Stage3MashGate.cs`: 연속 타격, 이펙트와 횟수 없는 안내.
- `Assets/Stage3/Editor/Stage3SceneBuilder.cs`: 씬과 지형·구간 장식 생성.
- `Assets/Stage3/Editor/Stage3Acceptance.cs`: 전체 재생, 지형, Mash, 메뉴·재시작 검증.

채보 기준은 분석으로 추정한 152 BPM, 위상 0.055초다. 테스트는 합성 입력으로 원본 판정 API와 Mash Press를 호출하고 홀드 종료는 원본 Complete를 호출한다. 에디터 지연으로 판정 시각을 놓친 합성 입력은 원본 Miss 처리를 호출하고 보고서에 별도 집계한다. 실제 키보드 지속 입력을 자동화한 테스트는 아니다.

## 이번 개정의 최종 확인

실제 Unity 음원 길이 53.160초 전체 재생 후 결과 화면 진입을 확인했다. 일반 105개와 Mash 3개의 판정이 모두 처리됐으며, 에디터 자동 입력 지연으로 놓친 일반 노트 1개는 Miss로 기록됐다. 세 Mash에서 내부 목표 이후에도 입력과 타격 이펙트가 계속 발생했고, 횟수·READY·완료 문구가 없는 화면을 확인했다. 지형 충돌·붕괴·카메라·음악 연속 재생·ESC·재시작·곡 선택·타이틀 검증은 모두 통과했다. 자동 검증 중 오디오와 DSP 시계 차이는 최대 134.7ms였으며, 실제 키보드 플레이로 조작감을 검증한 결과는 아니다. Stage1 원본 씬과 MP3 해시는 개정 전과 동일하다.
